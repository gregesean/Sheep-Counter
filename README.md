# Sheep Counter!

The sheep counter is very simple.
A sheep or wolf will appear on screen. if a sheep appears on screen, click the sheep button. If a wolf appears on screen, click the wolf button.
A counter above the sheep and wolf buttons will display how many sheep the user has clicked.
when a wolf is found, the counter will reset, and a list of how many sheep have been found will display under the buttons.

Happy hearding!
